How it works

Every run stays within spend, sandbox, and context bounds before protected checks decide the outcome.

  1. 1. Prepare & isolate

    Freeze the contract and verify the baseline fails; run tools inside OpenShell without host mounts or network access.

  2. 2. Meter & bound

    Route every model request through the counting relay, capping budget and idling at 300 seconds.

  3. 3. Gate & review

    Run protected checks the author cannot alter, then collect typed approvals from two distinct model families.

  4. 4. Checkpoint & ship

    Confirm exact-head CI before merging to main, while saving verified handover hashes and advisory memory notes.
